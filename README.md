# Медиа-компас

Учебное веб-приложение для подбора фильмов, компьютерных игр, книг и настольных игр. Пользователь выбирает понравившиеся объекты, после чего веб-приложение строит профиль интересов и ранжирует кандидатов по сходству жанров, тегов и описаний.

## Возможности

- поиск по локальному каталогу из 48 объектов и четырех категорий;
- добавление объектов в пользовательские предпочтения;
- content-based рекомендации на основе TF-IDF и косинусной близости;
- фильтрация по типу контента и минимальному рейтингу;
- объяснение каждой рекомендации;
- экспорт результата в CSV;
- внешний поиск книг через Open Library;
- внешний поиск фильмов через Wikipedia API;
- поиск игр и текущих цен через публичные данные Steam Store;
- добавление найденных внешних объектов в общий пул рекомендаций.

## Запуск

Требуется Python 3.11 или новее. Сторонние библиотеки не нужны.

Самый простой вариант для Windows — запустить файл `Запустить MediaCompass.bat`.

```powershell
cd MediaCompass
python app.py
```

После запуска открыть в браузере:

```text
http://127.0.0.1:8000
```

Другой порт можно задать параметром:

```powershell
python app.py --port 8080
```

## Тестирование

```powershell
python -m unittest discover -s tests -v
```

Тесты не выполняют реальные сетевые запросы: ответы внешних сервисов подменяются подготовленными данными.

## Алгоритм

1. Название, жанры, теги и описание каждого объекта объединяются в текст признаков.
2. Для всех объектов рассчитываются TF-IDF-векторы.
3. Векторы понравившихся объектов усредняются в профиль пользователя.
4. Между профилем и каждым кандидатом рассчитывается косинусная близость.
5. Итоговый балл учитывает похожесть, рейтинг и популярность:

```text
score = 0.72 * similarity + 0.18 * rating + 0.10 * popularity
```

Если внешний поиск пополнил пул, а его результаты не вошли в короткую выдачу,
последнее место занимает лучший внешний кандидат. Его рассчитанный балл при этом
не изменяется. Так пользователь видит результат парсинга и может сравнить его с
объектами учебного каталога.

## Структура проекта

```text
MediaCompass/
|-- app.py                    локальный HTTP-сервер и API приложения
|-- data/catalog.json         учебный каталог
|-- mediacompass/
|   |-- models.py             модель MediaItem
|   |-- catalog.py            загрузка и поиск каталога
|   |-- recommender.py        TF-IDF и ранжирование
|   `-- sources.py            клиенты внешних источников
|-- static/                   HTML, CSS, JavaScript и обложки
`-- tests/                    модульные тесты
```

## Ограничения

- локальный каталог создан для учебной демонстрации и не является полной базой;
- внешние источники требуют подключения к интернету и могут ограничивать частоту запросов;
- Steam Store API не является основной частью рекомендательного алгоритма;
- пользовательские аккаунты и постоянное хранение истории не реализуются в рамках MVP.

## Как используются внешние данные

Результаты поиска Open Library, Steam Store и Wikipedia сохраняются в памяти
текущей вкладки браузера. При расчете они передаются серверу вместе с локальным
каталогом, поэтому найденные книги, игры и фильмы могут попасть в рекомендации.
После обновления страницы временный внешний пул очищается.
